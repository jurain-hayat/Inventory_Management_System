
# 📦 Inventory Management System

A web-based Inventory Management System built using **PHP**, **MySQL (MariaDB)**, **XAMPP**, and **Git**.

---

## 🚀 Features

### Authentication

- Login
- Logout
- Session Management

### Dashboard

- Total Products
- Total Suppliers
- Total Sales
- Low Stock Counter

### Product Management

- View Products
- Add Product
- Edit Product *(Coming Soon)*
- Delete Product *(Coming Soon)*
- Search Products *(Coming Soon)*

### Supplier Management

- Add Supplier
- View Suppliers

### Sales Management

- Add Sales
- View Sales
